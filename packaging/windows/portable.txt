Fork It Up portable mode

While this file sits next to photocraft.exe, Fork It Up keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the Fork It UpData folder beside it, and writes
nothing to %APPDATA%. Copy the whole folder to move Fork It Up with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Photocraft) instead.
If Fork It UpData can't be written (for example on a read-only drive), Fork It Up says so and
uses %APPDATA%\Photocraft instead.
