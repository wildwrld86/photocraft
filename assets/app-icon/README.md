# Fork It Up app icon (placeholder)

The files in this directory are a **temporary placeholder** for the Fork It Up rebrand: a pink
fork on a dark rounded tile (`photocraft.svg`, `photocraft-small.svg`, `photocraft-1024.png`,
`photocraft.icns`, `photocraft.ico` and `hicolor/*/apps/io.github.wildwrld86.forkitup.*`).
The upstream PhotoCraft kitsune artwork was removed. Replace these with the final artwork and
regenerate the derived files with `packaging/icons.sh`.
